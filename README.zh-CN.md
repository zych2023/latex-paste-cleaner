# Latex Paste Cleaner

[English](README.md)

粘贴网页 / AI 对话内容到 Obsidian 时，自动清理 LaTeX 公式（`\\(...\\)` → `$...$`、`\\[...\\]` → `$$...$$`、双重转义、HTML 实体、Unicode 数学符号、多层嵌套转义损坏等），保留正文格式。

## 为什么需要

从网页（MathJax/KaTeX 渲染）或 AI 对话复制数学内容，经常得到严重损坏的 LaTeX：

- `\\(x^2\\)` / `\\[\\int dx\\]`（双重转义分隔符）
- `$\\boldsymbol{\\(\\boldsymbol{\\(y=x\\)}\\)}$`（HTML 渲染交错产生的多层嵌套转义）
- `\\bol\\(\\mathrm{d}s\\)ymbol{...}`（命令名被交错公式劈开）
- `&times;`、`&le;`（HTML 实体）
- `≥`、`×`、`α`（Unicode 数学符号）
- 裸 `[ ... ]` 块公式、半对/错位分隔符

插件识别粘贴内容中的公式区域，彻底清理，其余内容一律不动。

## 功能

- **智能粘贴拦截**：内容含 LaTeX 特征才触发；普通文本/代码完全原样放行
- **HTML 手术模式（默认）**：只替换公式节点为干净 LaTeX，正文粗体/列表等格式保留
- **纯文本模式**：全部以纯文本插入（最稳，无格式）
- **"清理当前笔记的 LaTeX 公式"命令**：修复存量笔记（选中区域优先，否则整篇）
- Unicode 数学符号（≥ × α 等）**只在公式区内**转换——正文永不误伤
- `\\[0,2π]` 这类标题转义方括号（非公式）原样保留

## 安装

1. 将 `latex-paste-cleaner/` 目录放入 vault 的 `.obsidian/plugins/`
2. Obsidian → 设置 → 第三方插件 → 启用 "Latex Paste Cleaner"
3. 无需重启（若列表未出现，重启 Obsidian）

## 使用

直接粘贴即可。剪贴板含 LaTeX 公式特征时，插件自动清理公式。

修复已有乱码笔记：打开笔记 → 命令面板（Ctrl+P）→ "清理当前笔记的 LaTeX 公式"。

### 设置

| 设置项 | 说明 |
|---|---|
| 启用粘贴拦截 | 粘贴内容含公式特征时自动清理。关闭后仅保留手动命令。 |
| 粘贴模式 | HTML 手术（保格式，默认）/ 纯文本清理（最稳） |
| 普通文本区修复 HTML 实体 | 公式外把 `&lt;` 等还原为 `<`。公式区内总是修复。 |

> **关于 HTML 粘贴的说明**：Obsidian 内置的"将粘贴的 HTML 转换为 Markdown"会把粘贴 HTML 中的 `$` 转义，导致行内公式不渲染（即使有本插件）。如果 HTML 粘贴后公式不渲染：在插件设置中切换为"纯文本"粘贴模式，或在 Obsidian → 设置 → 编辑器 中关闭"将粘贴的 HTML 转换为 Markdown"。

## 开发

```bash
cd .obsidian/plugins/latex-paste-cleaner
node tests/test-cleaner.cjs   # 67 个测试，无依赖
```

插件是单文件 `main.js`（Obsidian 插件加载器不支持相对路径 require）。核心函数额外导出，测试通过 mock obsidian 模块加载。

## 说明

- 仅当内容含 LaTeX 命令特征（`\frac`、`\\(`、`$$` 等）时触发；纯文本粘贴完全不受影响
- 核心逻辑防御性设计：无法确认/有歧义的内容一律不动，宁可不处理也不破坏
