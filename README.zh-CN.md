# Latex Paste Cleaner

[English](README.md)

一个 Obsidian 插件：粘贴网页 / AI 对话内容时，自动清理损坏的 LaTeX 公式（`\\(...\\)` → `$...$`、`\\[...\\]` → `$$...$$`、双重转义、HTML 实体、Unicode 数学符号、多层嵌套转义、命令名被劈开等），同时保留正文格式。

> **状态**：已提交 Obsidian 官方插件市场审核（等待中）。上架前请按下方"手动安装"步骤使用。

## 功能

- **智能粘贴拦截**：内容含 LaTeX 公式特征才触发；普通文本/代码完全原样放行
- **HTML 手术模式（默认）**：只替换公式节点为干净 LaTeX，正文粗体/列表等格式保留
- **纯文本模式**：全部以纯文本插入（最稳，无格式）
- **"清理当前笔记的 LaTeX 公式"命令**：修复已有乱码笔记（选中区域优先，否则整篇）
- Unicode 数学符号（≥ × α 等）**只在公式区内**转换——正文永不误伤
- `\\[0,2π]` 这类标题转义方括号（非公式）原样保留
- **双语界面**：中文 / English，在设置第一个选项切换

## 安装（市场审核通过前：手动安装）

1. 打开 [Releases 页面](https://github.com/zych2023/latex-paste-cleaner/releases)，下载最新版的 `latex-paste-cleaner-*.zip`（或直接下载仓库 ZIP）
2. 解压出 `latex-paste-cleaner/` 文件夹
3. 把整个文件夹放入你的 vault 插件目录：
   - `<你的vault>/.obsidian/plugins/latex-paste-cleaner/`
   - （`.obsidian` 是隐藏文件夹——看不到就开启"显示隐藏文件"）
4. 重启 Obsidian（或 设置 → 第三方插件 → 点"重新加载插件"）
5. Obsidian → 设置 → **第三方插件** → 启用 **Latex Paste Cleaner**

> 如果列表里没出现，完全重启 Obsidian。

## 使用方法

**直接粘贴就行**。剪贴板内容含 LaTeX 公式特征时，插件自动清理公式。

### 修复已有的乱码笔记

1. 打开含乱码公式的笔记
2. 命令面板（`Ctrl+P` / `Cmd+P`）
3. 运行 **"清理当前笔记的 LaTeX 公式"**
   - 有选中区域：只清理选中部分
   - 无选中：清理整篇

### 设置项

设置 → **第三方插件** → **Latex Paste Cleaner**：

| 设置项 | 说明 |
|---|---|
| **语言** | 中文 / English——切换后所有设置文案和命令名都会跟着切换 |
| 启用粘贴拦截 | 粘贴内容含公式特征时自动清理。关闭后仅保留手动命令。 |
| 粘贴模式 | **HTML 手术**（保格式，默认）/ **纯文本**（最稳） |
| 普通文本区修复 HTML 实体 | 公式外把 `&lt;` 等还原为 `<`。公式区内总是修复。 |

### 已知限制（HTML 粘贴时 `$` 被转义）

Obsidian 内置的"将粘贴的 HTML 转换为 Markdown"会把粘贴 HTML 里的 `$` 转义，导致行内公式不渲染（即使有本插件）。如果 HTML 粘贴后公式不渲染：

- 在插件设置中把"粘贴模式"切换为 **纯文本**，**或**
- 在 Obsidian → 设置 → **编辑器** 中关闭"将粘贴的 HTML 转换为 Markdown"

## 开发

```bash
cd <插件目录>
node tests/test-cleaner.cjs   # 67 个测试，无依赖
```

插件是单文件 `main.js`（Obsidian 插件加载器不支持相对路径 require）。核心函数额外导出，测试通过 mock obsidian 模块加载。

## 说明

- 仅当内容含 LaTeX 命令特征（`\frac`、`\\(`、`$$` 等）时触发；纯文本粘贴完全不受影响
- 核心逻辑防御性设计：无法确认/有歧义的内容一律不动，宁可不处理也不破坏
